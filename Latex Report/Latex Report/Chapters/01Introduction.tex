\section{Background and Summary}
Long term Live-Cell imaging is a very useful research tool when determining long term behavior of cell cultures in various situations. Commercial solutions are unable to provide adequate containment for the use within a Bio-Safety Level 3 (BSL-3) and often require the use of a separate containment enclosure, which introduces additional costs and complexity.

%This project focuses on the conceptual design of a low-cost Stage-Top Incubator that is capable of being utilized within a BSL-3 laboratory, without the requirement for additional containment. The primary focus with this project is specific suitability with Mycobacterium tuberculosis, however does consider other microbe requirements

This project focuses on the conceptual design of a bio-containment chamber which can be used within a BSL-3 lab to provide adequate containment for the long term observation of bacterial cultures. The main objective of this project is to allow long term observation of Mycobacterium tuberculosis (M. tb) grown in a multi-well plate.

This project is intended to provide an initial report on the feasibility of partaking in a further project to provide a complete incubation system for cell growth and observation.

\section{Scope and Limitations}
This project scope is limited to the following:
\begin{itemize}
	\item Preliminary Research
	\item Bio-Containment
	\item Compatibility with Multi-Well microtiter plates
	\item Primary containment of Mycobacterium tuberculosis (M. tb)
\end{itemize}

This project is limited to compatibility with a BSL-3 Lab and does not consider higher containment requirements. The chamber does not include any environmental control aspects and is limited to providing containment. The initial design is limited to compatibility with a Greiner 96 well microtiter plate. The use case of this project is limited to consider the requirements of M. tb
