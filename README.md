# **Feasibility Study Around Designing a BSL-3 Compatible Stage Top Bio Containment System**
---
This repository contains the information relating to the investigation of commercial stage top incubation systems in order to determine the feasibility of designing a custom incubator system that provides the necesary environmental control and containment capibilities that allow it to be utilised within a BSL-3 laboratory.
This project extends to provide some conceptual containment designs that could be utiliesd for a prototpye capable of basic temperature control.
